# 🌸 Gulabo – Pretty Things, Easy Prices

**Gulabo** is a simple and attractive online accessories shopping website designed to showcase cute, trendy, and affordable products in a clean, user-friendly interface.

The project focuses on creating a smooth shopping-style experience using **HTML, CSS, and JavaScript**, with product cards, categories, pricing, and interactive elements.

## ✨ Features

- 🛍️ Attractive product showcase
- 🎀 Accessories and trendy products
- 🔎 Simple and clean user interface
- 🏷️ Product prices and labels
- 📱 Responsive website design
- ⚡ Interactive product elements using JavaScript
- 💻 Beginner-friendly frontend implementation

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.

The website will open directly in your browser.

## 🎯 Project Purpose

Gulabo was created as a frontend web development project to practice building a modern, attractive, and easy-to-use shopping interface.

The project also explores how a small online accessories brand can present its products digitally with a simple and affordable design.
